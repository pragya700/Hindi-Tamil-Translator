# Hindi–Tamil Language Translator

A Spring Boot web application where students register, log in and translate text **Hindi → Tamil and Tamil → Hindi**.

> **Honest note about the translator:** the translation engine is a **basic dictionary demo**.
> - `src/main/resources/dictionary/hi_ta_dictionary.txt` (Hindi → Tamil, about 275 entries)
> - `src/main/resources/dictionary/ta_hi_dictionary.txt` (Tamil → Hindi, about 230 entries)
>
> The two files are written separately, not generated by swapping columns, because Hindi and Tamil
> do not map one-to-one (for example Tamil adds endings such as பள்ளிக்கு "to school").
> It only translates the words and phrases that are in the files, does not understand grammar and
> **cannot translate arbitrary sentences accurately**. Unknown words are left unchanged and
> reported to the user. Tamil verb endings do not show gender, so Tamil → Hindi uses masculine
> first-person Hindi forms (e.g. "जा रहा हूँ"). It works fully offline. No external API is used.
> The Tamil and Hindi entries were written without review by a native speaker, so please check
> them before presenting the project.

## Tech stack
Java 17 · Spring Boot 3.5.6 · Spring MVC · Thymeleaf · Spring Security (BCrypt, CSRF) ·
Spring Data JPA / Hibernate · MySQL 8 · Maven · HTML/CSS · small amount of JavaScript

## Features
- Registration (VIT ID, name, email, password, confirm password) with server-side validation
- Unique email and VIT ID (checked in code **and** enforced by MySQL UNIQUE constraints)
- BCrypt password hashing
- Login with email + password, session handling, secure logout (POST + CSRF)
- Protected translator page (`/home`) and API (`/api/translate`)
- Translator page: From/To language selectors, **Swap** button, Translate / Clear / Copy buttons,
  labels and placeholders that follow the chosen direction, loading indicator, example sentences
  per direction, responsive layout, no page reload (fetch API)
- `POST /api/translate` accepts `{"text", "sourceLanguage", "targetLanguage"}` (`hi` / `ta`) and
  returns 400 for blank text, missing/unsupported/identical languages and 503 if a dictionary
  could not be loaded (the other direction keeps working)

## Setup (Windows + VS Code)
1. Install **JDK 17+**, **Maven 3.9+**, **MySQL 8**, and the VS Code
   "Extension Pack for Java" and "Spring Boot Extension Pack".
2. Make sure MySQL is running. (The database `hindi_tamil_translator` is created automatically;
   `database/setup.sql` can also create it manually.)
3. Create your private config file:
   ```
   copy src\main\resources\application-local.properties.example src\main\resources\application-local.properties
   ```
   Open it and put your real MySQL username and password. It is ignored by Git.
   (Alternative: set environment variables `DB_USERNAME`, `DB_PASSWORD`, `DB_URL`.)
4. Run:
   ```
   mvn test
   mvn spring-boot:run
   ```
5. Open http://localhost:8080 , click **Create an account**, register, log in.

## Limitations and ideas for improvement
- Dictionary demo only. A real upgrade: integrate a translation API (e.g. a self-hosted
  LibreTranslate, after checking it supports `hi` -> `ta`) behind the same `TranslationService`.
- Save translation history per user (new entity + repository).
- Password reset by email, account lockout after repeated failures.
- Switch `ddl-auto=update` to Flyway migrations; add integration tests with Testcontainers.
- Add more languages by adding a dictionary file and a language code.
